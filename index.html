hermes agent

A single-user personal automation agent.

Summary. hermes agent is a private automation tool. It runs on one Windows computer owned by its operator and acts only on that operator's own Google Account. It is not distributed, not offered as a service, and has no other users.

What the application does

The agent automates the operator's own routine work: it reads and drafts email, organises files in Drive, manages calendar events, and reads and writes spreadsheets, documents, forms and presentations that belong to the operator.

Every action is started by the operator, on the operator's machine. The agent has no server, no hosted backend, and no multi-tenant component. No third party can use it.

Whose data it accesses

Only the operator's own data, in the operator's own Google Account. The agent never accesses another person's account, and it never acts on behalf of anyone else.

How Google user data is handled

  • Data is fetched directly from Google APIs to the operator's own computer.
  • Credentials are stored in a local file on that computer and nowhere else.
  • Data is never sold, shared, or transferred to any third party.
  • Data is never used to train or improve any machine-learning model.
  • No human other than the operator can read the data.

See the Privacy Policy for the full disclosure.

Google API scopes used

The agent requests access to Gmail, Google Calendar, Google Drive, Google Sheets, Google Docs, Google Slides, Google Forms and Google Contacts — limited to the operator's own account and to the narrowest scopes that each task requires.
