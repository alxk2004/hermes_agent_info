Privacy Policy

hermes agent — last updated 19 November 2026

1. Who this policy covers

hermes agent ("the application") is a private, single-user automation tool. It runs on one Windows computer owned by its operator, and it acts only on that operator's own Google Account. The application is not distributed and has no users other than its operator.

2. What Google user data the application accesses

The application accesses Google user data only after the operator grants consent on the Google OAuth consent screen. The scopes it requests, and why, are:

Google serviceWhy the application needs it
GmailTo read, search, label and draft email in the operator's own mailbox, so the operator can triage and reply.
Google CalendarTo read and create events in the operator's own calendars.
Google DriveTo list, read, upload and organise files in the operator's own Drive.
Google SheetsTo read and write the operator's own spreadsheets.
Google DocsTo read and write the operator's own documents.
Google SlidesTo read and write the operator's own presentations.
Google FormsTo create forms and read the operator's own form responses.
Google Contacts (People API)To look up names and addresses of the operator's own contacts when addressing email.

3. How the data is used

  • Data is used only to carry out tasks the operator explicitly requests.
  • Data is never used for advertising, profiling, or marketing.
  • Data is never used to train, fine-tune or improve any machine-learning or AI model.
  • Data is never used for any purpose unrelated to the operator's own request.

4. How the data is stored and protected

  • Google user data is retrieved directly from Google APIs to the operator's own computer.
  • OAuth credentials and refresh tokens are stored in a local file on that computer, protected by the operating system's user account permissions.
  • No copy of Google user data is stored on any server operated by a third party.

5. Sharing and disclosure

The application does not sell, rent, trade or transfer Google user data to any third party. Google user data is not disclosed to anyone except the operator. No human other than the operator can read it.

6. Retention and deletion

  • Data lives only as long as it is needed for the task at hand, on the operator's own computer.
  • The operator can delete all stored data at any time by deleting the local credential and cache files.
  • The operator can revoke the application's access at any time at myaccount.google.com/permissions. Revoking access stops all further access immediately.

7. Limited Use disclosure

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Children

The application is not directed to children and is not used by anyone under 18.

9. Changes to this policy

Any change to this policy is published on this page with a new "last updated" date.
